# 腰与腰取消控制

默认构建 `腰` 及 `腰キャンセル左`、`腰キャンセル右`。使用归一化的腰控制布局、层级、无权重规则和原生 MMD 付与旋转参数，按目标角色比例适配；执行时不依赖特定模型或项目，不复制外部角色尺寸、展示平移、D 骨、物理或其他辅助系统。

## 相对位置

[waist-profile.json](waist-profile.json) 保存归一化参数。锚点为本角色 `上半身.head`；尺度 W 为左右大腿 head（髋关节中心）的间距。X 指向角色左侧，Z 为骨架局部上方，Y=Z×X 指向后方。在此坐标系下：

- 腰 head 相对上半身 head：`W × (0, +0.249745, -0.060294)`，即位于躯干起点后方、略低处。
- 腰 tail 相对上半身 head：`W × (0, -0.161091, +0.306316)`，朝前上方显示。
- 腰取消 head 使用对应大腿原 head，tail 向上，长度约 `0.496972 × W`。
- 腰与取消骨局部 X 对齐角色左右轴。控制骨不承载非零蒙皮，不改变髋、膝、踝支点，不把 hips 权重转给腰。

这些比例是本 skill 的制作模板，不是 PMX 格式的强制标准。左右对称轴上的数值偏移归零，目标角色比例和骨长保留。髋间距退化或髋线明显不符合自动输入假设时报告适配需求，不用固定米数补骨。

## 层级与作用

```text
グルーブ
└─ 腰
   ├─ 上半身 → 胸部、头、手臂
   └─ 下半身
      ├─ 腰キャンセル左 → 左足 → 左ひざ → 左足首
      └─ 腰キャンセル右 → 右足 → 右ひざ → 右足首
```

腰是整体躯干旋转控制，上下半身绕其偏后支点一起运动。上下半身原有独立旋转仍然保留。腰的位置通道锁定、旋转通道开放；平移身体仍使用センター/グルーブ等控制。

左右腰取消位于髋关节，父级为下半身，对腰设置 `has_additional_rotation=True`、`additional_transform_bone=腰`、`additional_transform_influence=-1`，不附加位置。它们保留髋关节随腰移动的位移，同时抵消传向腿的腰旋转；下半身自己旋转时腿仍正常继承。取消骨同样锁位置、开放旋转。

使用 mmd_tools 的原生 `FnBone.apply_additional_transformation` 创建运行约束；不再叠加自定义 Copy Rotation。插件生成的 dummy/shadow 骨按实际标记纳入辅助集合，不当作额外的人体骨。腰分到体(上)，腰取消分到体(下)，三者均有标准日文名并进入对应显示枠。

## 创建、复用和保全

`scripts/waist_tools.py` 的 `compute_layout` 计算本角色布局，`build_edit_bones` 在构骨过程中创建/复用腰骨，`configure_controls` 写付与旋转参数。预检布局写 `rig-plan.json.waist_layout`，构建结果写 返回结果的 `waist_layout`。

已有无权重腰控制按语义复用，包括 `腰キャンセル.L/.R`、全名以及数字后缀别名；重复角色先合并引用与子级，再移除冗余骨，不产生第二套。存在非零蒙皮的腰候选先报告适配，不丢弃权重或擅自改造成无权重控制。动画/受约束的输入仍遵循静态源预检要求；不要直接把复杂参考 PMX 当成普通 VRM 源重新转换。

改变父级时保持原骨 Rest 矩阵与绑定几何；只调整新控制骨的布局、下半身既有整理规则和明确的脚链规则。源模型和参考模型不修改。

## 验证

`validate_waist` 已接入 `validate_rig`、`backtest_rig`：检查三根骨唯一性、相对位置/轴、层级、通道锁定、无新增蒙皮、`-1` 旋转来源与倍率，连同集合/显示枠由综合验收检查。

动作探针暂时关闭 IK，分别沿腰局部 X/Y/Z 旋转 ±10°，测量躯干绕腰的响应、髋关节随动和腰取消/大腿旋转；随后测试下半身独立旋转，不应带动上半身。结束时恢复原 Pose 通道及 IK 开关，再运行原有连续脚 IK 回测。

[waist-motion-reference.json](waist-motion-reference.json) 来自参考骨架的隔离快照，用于比较角色坐标系中的实际旋转响应。mmd_tools 原生 `-1` 付与旋转在某些轴向并非精确的四元数逆：本参考 ±10° 探针中 Y/Z 对应约 0.87° 残差。该残差被如实报告，验收比较新骨架与参考响应的误差（≤0.1°），不把参考残差改写为零，也不靠放宽阈值掩盖新问题。更换原生约束实现时需重新核查参考响应。

本阶段仍不导出 PMX，也不声称服装、所有体型或极端大角度动作已验证。已有工作副本若来自旧版无腰构建器，应另行迁移并复测，不绕过 `auto_rig_version` 把整个已转换骨架再烘焙一次。
